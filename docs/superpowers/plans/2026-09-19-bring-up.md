# Bring-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Elgato 4K60 Pro Mk.2 in this PC captures 4K60 SDR video and audio through a DKMS-installed fork of the sc0710 driver, verified in ffmpeg, mpv and OBS.

**Architecture:** A public project repo holds packaging, verification scripts and docs; the driver is a git submodule pointing at a GitHub fork of `Nakildias/sc0710`, pinned to a reviewed commit. The module is first built and loaded by hand without installing anything, then packaged as a pacman package that registers it with DKMS for both installed kernels, with a modprobe blacklist so it never loads automatically at boot during bring-up.

**Tech Stack:** Linux kernel module (C, built with clang/LLVM through kbuild), DKMS, pacman/makepkg, bash, v4l2-ctl, ffmpeg, ALSA/PipeWire, mpv, OBS, git, gh.

**Spec:** `docs/superpowers/specs/2026-09-19-bring-up-design.md`

## Global Constraints

- Project repo: `mkeguy106/elgato-4k60-pro-mk2-linux`, public, GPL-2.0-or-later. Local directory stays `~/elgato_4k_capture`.
- Driver fork: `mkeguy106/sc0710`, a GitHub fork of `Nakildias/sc0710`. Pinned commit: `ea0a71215e24a33aa8b26b5cc66e3592c9dfdfe1` (version file `2026.09.02-1`). This is the commit whose Makefile, dkms.conf and packaging were reviewed. Do not move the pin during this plan.
- `~/sc0710` is never touched.
- Commit messages never mention AI, Claude, or automated generation, and carry no `Co-Authored-By` trailer.
- Card: PCI `12ab:0710`, subsystem `1cfa:000e`, at `0000:03:00.0`. Kernels: `6.18.50-3-cachyos-lts` (running, clang-built) and `7.2.5-1-cachyos`.
- Package name: `sc0710-mk2-dkms`. It conflicts with and does not provide `sc0710-dkms-git`.
- Never run the fork's `scripts/install-sc0710.sh` or `scripts/sc0710-cli.sh`.
- Never use `rmmod -f`. Force-unloading with an open capture descriptor is a use-after-free.
- `sudo` works without a password prompt from this session. That is capability, not permission: every root command is its own Bash call, never chained with `&&` to other commands, with a plain-language description so the user can approve or decline it.
- The user's locale uses a comma as decimal separator. Every script that parses or compares numbers runs with `LC_ALL=C`.
- Tearing at 4K60 is a known upstream problem: record it, do not treat it as failure. Bring-up fails only if the module will not build or load, if no correct picture or no audio can be captured at all, or if the machine locks up or panics. On any of those, stop and report.
- Artifacts (logs, captured frames, audio) go in `out/`, which is gitignored.

Create `scripts/verify-lib.sh`:

```bash
#!/usr/bin/env bash
# Functions for scripts/verify.sh. Source this file; do not execute it.
# Callers must run with LC_ALL=C: number parsing assumes a dot decimal separator.

SYSFS_ROOT="${SYSFS_ROOT:-/sys}"
SC0710_VENDOR="0x12ab"
SC0710_DEVICE="0x0710"

# Print the PCI address of the first sc0710 card, e.g. 0000:03:00.0.
find_pci_addr() {
    local d
    for d in "${SYSFS_ROOT:-/sys}"/bus/pci/devices/*; do
        [[ -r "$d/vendor" && -r "$d/device" ]] || continue
        if [[ "$(<"$d/vendor")" == "$SC0710_VENDOR" && "$(<"$d/device")" == "$SC0710_DEVICE" ]]; then
            basename "$d"
            return 0
        fi
    done
    return 1
}

# _class_child_of CLASS_GLOB ADDR: print the name of the first class device
# whose parent device is PCI device ADDR. The driver registers both its V4L2
# node and its ALSA card with the PCI device as parent.
_class_child_of() {
    local glob="$1" addr="$2" c
    for c in $glob; do
        [[ -e "$c/device" ]] || continue
        if [[ "$(basename "$(readlink -f "$c/device")")" == "$addr" ]]; then
            basename "$c"
            return 0
        fi
    done
    return 1
}

# Print the V4L2 device node for the card at PCI address $1, e.g. /dev/video2.
find_video_node() {
    local name
    name="$(_class_child_of "${SYSFS_ROOT:-/sys}/class/video4linux/video*" "$1")" || return 1
    echo "/dev/$name"
}

# Print the ALSA card index for the card at PCI address $1, e.g. 3.
find_alsa_card() {
    local name
    name="$(_class_child_of "${SYSFS_ROOT:-/sys}/class/sound/card*" "$1")" || return 1
    echo "${name#card}"
}

# stdin: `v4l2-ctl --query-dv-timings`. Print "WIDTHxHEIGHT FPS".
parse_dv_timings() {
    local text w h fps
    text="$(cat)"
    w="$(grep -oP 'Active width:\s*\K[0-9]+' <<<"$text")" || return 1
    h="$(grep -oP 'Active height:\s*\K[0-9]+' <<<"$text")" || return 1
    fps="$(grep -oP '\(\K[0-9.]+(?= frames per second\))' <<<"$text")" || return 1
    echo "${w}x${h} ${fps}"
}

# $1: "WIDTHxHEIGHT FPS". True for 3840x2160 at 59..60.5 fps (59.94 is valid 4K60).
is_4k60() {
    local res="${1% *}" fps="${1#* }"
    [[ "$res" == "3840x2160" ]] || return 1
    awk -v f="$fps" 'BEGIN { exit !(f >= 59 && f <= 60.5) }'
}

# stdin: `v4l2-ctl --list-formats-ext`. True if format FOURCC lists size WxH.
format_has_size() {
    local fourcc="$1" size="$2"
    awk -v f="'$fourcc'" -v s="$size" '
        /^[[:space:]]*\[[0-9]+\]:/ { cur = ($2 == f) }
        cur && /Size:/ && index($0, s) { found = 1 }
        END { exit !found }'
}

# stdin: ffmpeg stderr. Print the last reported frame count.
parse_frame_count() {
    grep -oP 'frame=\s*\K[0-9]+' | tail -n 1 | grep .
}

# True if FRAMES over SECONDS is 59..60.5 fps.
frames_ok() {
    awk -v n="$1" -v s="$2" 'BEGIN { r = n / s; exit !(r >= 59 && r <= 60.5) }'
}

# stdin: ffmpeg volumedetect output. Print the mean volume in dB, e.g. -23.5.
parse_mean_volume() {
    grep -oP 'mean_volume:\s*\K-?[0-9.]+' | tail -n 1 | grep .
}

# True if mean volume $1 (dB) is louder than -60 dB, i.e. not silence.
volume_ok() {
    awk -v v="$1" 'BEGIN { exit !(v > -60) }'
}

# Print the default PipeWire sink and source node names.
audio_defaults() {
    local t
    for t in SINK SOURCE; do
        printf '%s=%s\n' "$t" \
            "$(wpctl inspect "@DEFAULT_AUDIO_${t}@" | grep -oP 'node\.name = "\K[^"]+' | head -n 1)"
    done
}
```

```bash
#!/usr/bin/env bash
# Unload the sc0710 module. PipeWire and WirePlumber keep the V4L2 and ALSA
# nodes open even when no application is capturing, so rmmod refuses until
# they let go. This stops them, unloads, and starts them again. Desktop audio
# drops out for a few seconds. rmmod -f is never used: force-unloading with an
# open capture descriptor is a use-after-free.
set -uo pipefail

if ! lsmod | grep -q '^sc0710 '; then
    echo "sc0710 is not loaded"
    exit 0
fi

units=(pipewire.socket pipewire-pulse.socket pipewire.service pipewire-pulse.service wireplumber.service)
restart_audio() { systemctl --user start "${units[@]}"; }
trap restart_audio EXIT

systemctl --user stop "${units[@]}"

if sudo rmmod sc0710; then
    echo "sc0710 unloaded"
    exit 0
fi

echo "rmmod refused; processes still holding the device:" >&2
sudo fuser -v /dev/video* /dev/snd/* >&2 || true
exit 1
```

- [ ] **Step 1: Write `scripts/verify.sh`**

```bash
#!/usr/bin/env bash
# Automated bring-up checks for the Elgato 4K60 Pro Mk.2.
# Spec: docs/superpowers/specs/2026-09-19-bring-up-design.md, section 3.
# Needs: module loaded, console connected, SDR 3840x2160 at 60 Hz, sound playing.
set -uo pipefail
export LC_ALL=C

here="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
# shellcheck source=verify-lib.sh
source "$here/verify-lib.sh"
out="$here/../out"
mkdir -p "$out"

seconds=30
fails=0
report() { # report NAME STATUS DETAIL
    printf '%-14s %-5s %s\n' "$1" "$2" "$3"
    [[ "$2" == FAIL ]] && fails=$((fails + 1))
    return 0
}

if lsmod | grep -q '^sc0710 '; then
    report module PASS "sc0710 is loaded"
else
    report module FAIL "sc0710 is not loaded"
    exit 1
fi

addr="$(find_pci_addr)" && node="$(find_video_node "$addr")" && card="$(find_alsa_card "$addr")"
if [[ -z "${node:-}" || -z "${card:-}" ]]; then
    report devices FAIL "pci=${addr:-none} video=${node:-none} alsa=${card:-none}"
    exit 1
fi
report devices PASS "pci=$addr video=$node alsa=hw:$card,0"

if timings="$(v4l2-ctl -d "$node" --query-dv-timings 2>&1 | parse_dv_timings)" && is_4k60 "$timings"; then
    report signal PASS "$timings"
else
    report signal FAIL "${timings:-no timings detected} (want 3840x2160 at 60)"
fi

formats="$(v4l2-ctl -d "$node" --list-formats-ext 2>&1)"
for fourcc in YUYV BGR3; do
    if format_has_size "$fourcc" 3840x2160 <<<"$formats"; then
        report "format-$fourcc" PASS "3840x2160 listed"
    else
        report "format-$fourcc" FAIL "3840x2160 not listed"
    fi
done

start="$(date '+%F %T')"
ffmpeg -hide_banner -nostdin -y \
    -f v4l2 -input_format yuyv422 -i "$node" \
    -f alsa -ac 2 -ar 48000 -i "hw:$card,0" \
    -map 0:v -t "$seconds" -f null - \
    -map 1:a -t "$seconds" "$out/audio.wav" \
    2>"$out/capture.log"
if frames="$(parse_frame_count <"$out/capture.log")" && frames_ok "$frames" "$seconds"; then
    report capture PASS "$frames frames in ${seconds}s"
else
    report capture FAIL "${frames:-0} frames in ${seconds}s (want 59-60.5 fps); see out/capture.log"
fi

journalctl -k --since "$start" --no-pager | grep -i sc0710 \
    | grep -iE 'error|fail|timeout|tear|short|resync|overrun' >"$out/kernel-errors.log"
if [[ -s "$out/kernel-errors.log" ]]; then
    report kernel-log FAIL "$(wc -l <"$out/kernel-errors.log") suspicious line(s); see out/kernel-errors.log"
else
    report kernel-log PASS "no sc0710 errors during capture"
fi

if [[ -s "$out/audio.wav" ]] \
    && vol="$(ffmpeg -hide_banner -nostdin -i "$out/audio.wav" -af volumedetect -f null - 2>&1 | parse_mean_volume)" \
    && volume_ok "$vol"; then
    report audio PASS "mean volume ${vol} dB"
else
    report audio FAIL "mean volume ${vol:-unknown} dB (want above -60; is the console playing sound?)"
fi

if ffmpeg -hide_banner -nostdin -y -f v4l2 -input_format yuyv422 -i "$node" \
        -frames:v 1 "$out/frame.png" 2>>"$out/capture.log" \
    && ffmpeg -hide_banner -nostdin -y -i "$out/frame.png" -vf scale=1920:-1 \
        "$out/frame-1080.png" 2>>"$out/capture.log"; then
    report picture LOOK "inspect out/frame-1080.png: correct image, aligned, right colours"
else
    report picture FAIL "could not save a frame; see out/capture.log"
fi

if [[ -f "$out/audio-defaults.before" ]]; then
    if diff -q "$out/audio-defaults.before" <(audio_defaults) >/dev/null; then
        report audio-default PASS "default sink and source unchanged"
    else
        report audio-default FAIL "default sink or source changed since baseline"
    fi
else
    report audio-default LOOK "no baseline at out/audio-defaults.before"
fi

echo
if (( fails )); then
    echo "$fails check(s) failed"
    exit 1
fi
echo "all automated checks passed"
```

```bash
# Maintainer: mkeguy106
# Local package: DKMS tree built from ../driver at its checked-out commit.
pkgname=sc0710-mk2-dkms
_modname=sc0710
pkgver=2026.09.02.1.r223.ea0a712
pkgrel=1
pkgdesc="DKMS driver for the Elgato 4K60 Pro Mk.2 capture card (mkeguy106/sc0710 fork)"
arch=('x86_64')
url="https://github.com/mkeguy106/elgato-4k60-pro-mk2-linux"
license=('GPL-2.0-or-later')
depends=('dkms')
makedepends=('git')
conflicts=('sc0710-dkms-git' 'sc0710-dkms' 'sc0710')
install=${pkgname}.install
source=('sc0710-blacklist.conf')
sha256sums=('SKIP')

_driver_dir="$(realpath "${startdir:-$PWD}/../driver")"
_commit="$(git -C "${_driver_dir}" rev-parse HEAD)"

pkgver() {
    local _ver
    _ver="$(git -C "${_driver_dir}" show "${_commit}:version" | head -n 1 | tr - . | tr -d '[:space:]')"
    printf '%s.r%s.%s' "${_ver}" \
        "$(git -C "${_driver_dir}" rev-list --count "${_commit}")" \
        "$(git -C "${_driver_dir}" rev-parse --short=7 "${_commit}")"
}

prepare() {
    rm -rf "${srcdir}/tree"
    install -d "${srcdir}/tree"
    git -C "${_driver_dir}" archive "${_commit}" \
        Makefile dkms.conf version lib LICENSE scripts/sc0710-dkms-make.sh \
        | tar -x -C "${srcdir}/tree"
}

package() {
    local dest="${pkgdir}/usr/src/${_modname}-${pkgver}"

    install -d "${dest}"
    cp -r "${srcdir}/tree/Makefile" "${srcdir}/tree/dkms.conf" \
          "${srcdir}/tree/version" "${srcdir}/tree/lib" "${dest}/"
    sed -i "s/^PACKAGE_VERSION=.*/PACKAGE_VERSION=\"${pkgver}\"/" "${dest}/dkms.conf"

    # dkms.conf's MAKE[0] calls this wrapper by absolute path.
    install -Dm755 "${srcdir}/tree/scripts/sc0710-dkms-make.sh" \
        "${pkgdir}/usr/lib/sc0710/sc0710-dkms-make.sh"
    install -Dm644 "${srcdir}/tree/LICENSE" \
        "${pkgdir}/usr/share/licenses/${pkgname}/LICENSE"
    install -Dm644 "${srcdir}/sc0710-blacklist.conf" \
        "${pkgdir}/etc/modprobe.d/sc0710-blacklist.conf"
}
```

```markdown
## Leads for sub-project 2 (10-bit spike)

- The driver already has a module parameter `color_deep` (`lib/sc0710-video.c`):
  "MCU color depth prefer: 0=8-bit, 1=10-bit request, 2=auto", commented as the
  Windows `CustomAnalogVideoNativeColorDeepProperty`. Someone has mapped the
  request side of 10-bit; what is missing is a 10-bit pixel format on the DMA
  side (the driver exposes only YUYV, BGR24, and NV12 for the Cam Link Pro).
- `/proc/sc0710` dumps BAR0 and BAR1 registers; `mcu_scan=1` hexdumps MCU
  subaddresses 0x00-0x7f. Both are read-only diagnostics to compare against
  register state captured under Windows in SDR and HDR10 modes.
- Bandwidth: the link is PCIe Gen2 x4 (about 2 GB/s). 4K60 at 10-bit 4:2:2
  packed in 16-bit samples is about 1,99 GB/s raw; at 10-bit 4:2:0 (P010) about
  1,49 GB/s. Which one the card emits decides whether 4K60 10-bit fits.
```
